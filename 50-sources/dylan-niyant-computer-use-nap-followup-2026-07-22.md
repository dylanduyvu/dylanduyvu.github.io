# Dylan and Niyant: computer-use NAP contribution follow-up

## Context

After studying Niyant's thesis and proposing a Tab-style computer navigation predictor, Dylan asked Niyant what work he would assign to Dylan, or to a second pair of hands generally, if they wanted to contribute to the vision.

## Reported answer

Dylan reported Niyant's answer on July 22, 2026:

> build this computer use nap thing

This note preserves Dylan's contemporaneous paraphrase. The exact Slack message and surrounding transcript were not supplied, so the wording should not be treated as a verbatim quotation from Niyant.

## What changed

Computer-use NAP is no longer merely Dylan's adjacent alternative to Niyant's next-write experiment. Niyant explicitly identified it as useful contribution work for a second pair of hands. It can therefore proceed as a complementary branch inside the same vision:

- Niyant continues the static next-write and personal-context comparison.
- Dylan tests whether exact semantic computer destinations are diverse, personally predictable, and valuable as a keyboard-first product interaction.

This resolves the earlier question of whether Niyant sees the navigation target as outside the vision. It does not resolve the implementation scope. “Computer-use NAP” could still mean exact destination routing, broader action-sequence prediction, or a later live Tab interface.

## Agreed direction

Dylan decided not to use Tabracadabra as a separate experiment. Tabracadabra is useful prior art for an in-line personalized writer, but it does not test Dylan's distinct router hypothesis. The immediate plan is to go directly to a shadow-mode experiment that predicts the next exact semantic focus and compares it with trivial navigation baselines before building a live interface.

## Evidence boundary

Niyant's assignment establishes strategic relevance, not technical feasibility, product value, or a validated experiment design. The first proof should remain narrow and falsifiable.
